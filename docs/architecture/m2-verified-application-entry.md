# Verified directory application entry

**Frozen for bounded implementation dispatch, 5 November 2026.** The coordinator and both component owners completed feasibility readback. Milestone acceptance requires the frozen-source reviews, real-directory oracle and combined gate. This is a one-shot, single-threaded, closed-image Java SE 21 application profile. The normal entry is a real public static main with a genuine empty String array. It runs on CrabSpot. Java tools are fixture producers and external references.

## External operation and authority

Add a library to the existing crabspot-launcher package. It owns orchestration and filesystem policy and depends on classfile, verifier, runtime and interpreter. The existing inspect subcommand and lower-level APIs keep their behavior. Add the subcommand `crabspot run --platform DIR --classes DIR BINARY.MAIN`. Both switches occur exactly once before the single binary name, in either order. No trailing application arguments or preview flag. Print nothing on successful return and exit zero. Usage errors exit 2. All other failures exit 1 with the failing stage and available class/method/PC on stderr. Diagnostics distinguish Java and host categories without matching a vendor's English text. Never start another VM, invoke a compiler to supply a class, or consult CLASSPATH, PATH or JAVA_HOME to resolve a missing file.

Public launcher entry:

```rust
pub struct ApplicationDirectories<'a> {
    pub platform: &'a Path,
    pub classes: &'a Path,
}
pub struct StaticIntObservation<'a> {
    pub binary_class: &'a str,
    pub field: &'a str,
}
pub fn run_directory_application(
    directories: ApplicationDirectories<'_>, entry: &str,
    observations: &[StaticIntObservation<'_>], options: ApplicationOptions,
) -> Result<ApplicationRun, Box<ApplicationError>>;
pub struct ApplicationRun {
    pub completion: ApplicationCompletion,
    pub static_ints: Vec<i32>,
    pub usage: ApplicationUsage,
}
pub enum ApplicationCompletion {
    Returned,
    SuppliedUncaught { phase: EntryEvaluation, class_name: JavaString },
    ExecutionFailed { phase: EntryEvaluation, error: Box<ExecutionError> },
}
```

A library caller supplies paths, the entry name and optional read-only observations. All IDs, loaders, facts, graph edges and method handles come from input bytes and the two namespace rules below. No caller-supplied proof success, heap, runtime class table, resolver, static initializer or chosen target can enter this API. Top-level errors cover image construction, query validation and execution-environment setup before entry dispatch. Once the first engine evaluation for N or M is called, report its genuine completion (including original structured engine error) together with observed static effects including a failed named child initializer before inherited main could execute. An invalid application cannot obtain effects from a partially verified image. No public handle survives the call. Use an inner lexical scope for InitializationSession and sequence immutable verification before taking the mutable member-domain borrow. An owner containing a reference back into itself is unnecessary.

## Resource and error ownership
