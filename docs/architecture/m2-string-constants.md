## Results visible to Java

An enabled heap has one bootstrap String role and one initially empty interning pool shared by all classes/loaders in that heap. Equality of keys means exact ordered equality of UTF-16 code units. No decoding through Unicode scalars, normalization, trimming, or modified-UTF8 re-encoding is allowed. A fresh String argument is a distinct managed instance for every position, including duplicate empties. Calling the real bootstrap native String.intern returns a prior equal canonical object when present and otherwise installs and returns **the receiver itself**. Literal derivation returns an existing equal pooled object or creates and interns a new one. The order in which distinct execution paths first access equal content is observable. A different heap starts a separate pool, including if the loading domain and registry are shared. [JVMS §5.1](https://docs.oracle.com/javase/specs/jvms/se21/html/jvms-5.html#jvms-5.1), [Java SE 21 String.intern](https://docs.oracle.com/en/java/javase/21/docs/api/java.base/java/lang/String.html#intern()).

Strings are valid nonnull Java references to the bound String class. Use existing cast/assignability, Object.getClass, fields, array-store, catch-category, monitor and argument/return services. Equal noninterned argument objects have different lock keys. Intern/literal aliases share one ordinary heap-reference lock. A String mirror and any String instance use separate keys. Literal derivation, allocation of argument values, and an instance-native call must neither request active initialization of String nor manufacture a Completed class status. Ordinary genuine static active-use still follows the initializer scheduler. No public mutable backing array, private Java layout, suppressed real initializer, invented native binding or fabricated Throwable.

## Pool, literal sites and funding

Per-heap literal site key (canonical declaring ClassId, actual CONSTANT_String CP index) maps to an issued canonical handle. The containing UTF8 index supplies exact units. Separate sites may join one object; repeated uses of one site must avoid revisiting its contents. A String constant needs no Class CP for java/lang/String and no interpretation of its text as a type name. No domain-global handle cache or cached host policy failure. Only inspect immutable admitted CP tags and checked links. A hit validates current origin/authority, handle, and fixed scalar affinitites; avoid comparing all stored units to revalidate an internally issued site. A structurally wrong load category fails before String service effects. No charge to mirror class sites.

Each string service has a heap-lifetime work ledger, independent of instruction fuel and method/field/name-resolution work. Charge before each operation and retain accepted charges on failure. Steps: one site probe for each valid literal request; a hit costs exactly one. On miss preflight site cap then stage a site reservation; check String→Utf8 link before reading payload. Charge one for that checked link. For a content lookup, prepay length units for hashing plus one bucket probe; for each candidate pay one probe, then length for full equality only if lengths match, including an equal key. Fresh string allocation pays one provisioning unit plus length for copying; canonical insertion pays one provisioning unit. When an already-issued receiver has a canonical flag, direct intern costs one receiver/probe unit, then returns it without a content scan. For a noncanonical intern request pay the same first unit and perform content lookup; actual content may be borrowed through a stable heap handle. Precompute/copy only under those charges. Hash with a bounded security-conscious implementation, cache scalar fingerprints for table growth, and use checked candidate chains or buckets for collisions. Fixed-key hash-table growth is permitted under the corresponding actual-demand reservations; never repeatedly rehash or clone String contents for growth. Bound adversarial equal-length collisions by the work ledger. No allocation by policy maximum. Compute whole debits with checked arithmetic; exhaustion/overflow precedes work/publication and reports the accepted usage, limit and required value when representable.

Each request is transactional with respect to new objects, units, canonical membership, roots and literal sites. On a valid cold site preflight site capacity before deriving content; if lookup hits, publish only the site. On a miss check pool cap, then object cap, retained units, existing instance cap/arena bounds, and work for fresh provisioning and insertion. Reserve every newly needed buffer/map/bucket/root/site/arena record and acquire disjoint mutable commit targets before first logical mutation. Failure leaves those logical counts unchanged; prior independent successful calls remain visible, including a canonical value established by an argument. Interning a fresh receiver never copies its units into a second owned pool key or charges another object; canonical roots retain actual receivers. Strong canonical roots are separate from argument array and static roots. Tests need forced fingerprint collisions, every reservation failpoint, overflow, foreign/stale handles and thousands of repeated hits sharing a 65,535-byte source constant. Pin exact zero, inclusive, one-less and MAX controls.
